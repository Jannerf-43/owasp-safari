Vulnerability 02

SQL Injection 등 인젝션

입력값이 검증되지 않은 채 명령어나 쿼리로 처리될 때 발생하는 대표적인 취약점입니다.

개념

공격자는 입력창에 일반 데이터가 아닌 SQL 조각이나 명령문을 넣어 서버의 의도와 다른 동작을 유도할 수 있습니다.

공격 흐름

  1. 사용자 입력 전달
  2. 서버가 입력값을 쿼리에 결합
  3. 검증 실패 시 쿼리 구조 변경
  4. 인증 우회 또는 데이터 노출 가능

방어 대책

  • Prepared Statement 사용
  • 입력값 검증
  • DB 계정 권한 최소화
  • 에러 메시지 노출 제한
