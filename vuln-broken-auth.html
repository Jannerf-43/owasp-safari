Vulnerability 01

취약한 인증 Broken Authentication

인증 로직이나 세션 관리가 약하면 공격자가 다른 사용자처럼 로그인하거나 권한을 탈취할 수 있습니다.

개념

약한 비밀번호 정책, 무차별 대입 방어 부재, 세션 만료 미흡, 토큰 노출 등이 대표적인 원인입니다.

공격 흐름

  1. 사용자 로그인 시도
  2. 서버 인증 검사
  3. 세션 또는 토큰 발급
  4. 관리 실패 시 계정 탈취 가능

방어 대책

  • 강한 비밀번호 정책 적용
  • 로그인 실패 횟수 제한
  • 세션 만료와 재발급 관리
  • 다중 인증 MFA 적용
