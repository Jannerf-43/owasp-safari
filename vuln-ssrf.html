Vulnerability 06

서버 측 요청 위조 SSRF

서버가 사용자가 입력한 URL로 요청을 보내도록 설계된 기능에서 내부망 접근 위험이 생길 수 있습니다.

개념

이미지 불러오기, URL 미리보기, 웹훅 테스트처럼 서버가 외부 주소에 접근하는 기능에서 자주 설명됩니다.

공격 흐름

  1. 사용자가 URL 입력
  2. 서버가 해당 URL 요청
  3. 내부 주소 요청도 허용
  4. 내부 서비스 정보 노출 가능

방어 대책

  • 허용 도메인 목록 사용
  • 내부 IP 대역 차단
  • 리다이렉트 검증
  • 서버 네트워크 권한 제한
