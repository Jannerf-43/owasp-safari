Vulnerability 03

크로스 사이트 스크립팅 XSS

사용자 입력이 검증 없이 페이지에 출력될 때, 브라우저에서 원치 않는 스크립트가 실행될 수 있습니다.

개념

게시판 댓글, 검색어, 프로필 소개처럼 사용자의 입력을 다시 화면에 보여주는 기능에서 자주 설명되는 취약점입니다.

공격 흐름

  1. 사용자 입력 저장 또는 반영
  2. 페이지가 입력값 출력
  3. 브라우저가 스크립트로 해석
  4. 쿠키 탈취·피싱·화면 변조 위험

방어 대책

  • HTML 이스케이프 처리
  • Content Security Policy 적용
  • 입력값 검증
  • 출력 위치에 맞는 인코딩
