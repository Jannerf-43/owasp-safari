Vulnerability 05

암호화 오류 Cryptographic Failures

민감정보를 평문으로 저장하거나 약한 암호화 방식을 사용하면 정보 유출 피해가 커집니다.

개념

비밀번호, 주민번호, 결제 정보, 인증 토큰은 저장과 전송 과정에서 적절히 보호되어야 합니다.

공격 흐름

  1. 민감정보 입력
  2. 평문 저장 또는 약한 해시 사용
  3. DB 유출 발생
  4. 계정 탈취와 개인정보 피해 확대

방어 대책

  • HTTPS 적용
  • 비밀번호 단방향 해시와 Salt 사용
  • 민감정보 최소 저장
  • 안전한 암호화 알고리즘 사용
