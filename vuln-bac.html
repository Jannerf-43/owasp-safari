Vulnerability 04

취약한 접근 제어 Broken Access Control

권한 확인이 부족하면 사용자가 접근하면 안 되는 데이터나 기능에 접근할 수 있습니다.

개념

URL 파라미터 조작, 관리자 페이지 직접 접근, 다른 사용자의 리소스 ID 조회 등이 대표적인 예시입니다.

공격 흐름

  1. 사용자 요청 발생
  2. 서버가 권한 확인 생략
  3. 다른 사용자의 리소스 접근
  4. 개인정보 노출 또는 기능 오남용

방어 대책

  • 서버 측 권한 검사
  • 기본 차단 정책
  • 리소스 소유자 확인
  • 관리자 기능 분리
